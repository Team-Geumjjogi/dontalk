# playground — 개인 실험실 🧪

**자유롭게 시도해 보는 공간**입니다. 코드가 지저분해도, 실패해도, 리뷰 없이 올려도 됩니다.

## 규칙
1. 내 이름으로 폴더를 만듭니다: `playground/eunje/`
2. 내 폴더 안에서만 작업합니다. (다른 사람 폴더는 읽기만)
3. 노트북은 `_template.ipynb`를 복사해서 시작하면 편합니다.
4. **데이터 파일(.json/.jsonl/.csv 등 큰 파일)과 모델 파일은 올리지 않습니다.**
5. 의미 있는 결과가 나오면 → `experiments/LOG.md`에 한 줄 기록
6. 코드가 쓸 만하면 → `.py`로 정리해서 `ai/`나 `ml/`로 옮기는 PR(승격)

## 이런 걸 올리면 좋아요
- 임베딩 모델 비교 노트북, 검색 결과 눈으로 확인한 노트북
- 프롬프트 바꿔가며 Base EXAONE 답변 비교한 기록
- 배운 개념 정리 (`.md`)
