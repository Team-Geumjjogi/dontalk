# Colab 사용 가이드 (계정 1개 공유)

## 원칙
- **계정이 1개**라서 한 번에 한 명만 GPU 세션을 사용합니다. 사용 전후에 팀 채팅방에 알립니다. ("지금 쓸게요 / 끝났어요")
- **컴퓨트 유닛은 한정**되어 있고 A100은 소모가 빠릅니다. 정확한 잔여량은 Colab 화면에서 확인하세요.
- 사용하지 않을 때는 **런타임 연결을 반드시 해제**합니다. (런타임 → 세션 관리 → 종료)

## 단계별 사용
| 단계 | 하는 일 | 권장 GPU |
|---|---|---|
| 연습 | 작은 모델 + 작은 데이터로 학습 코드가 도는지 확인. 한 명이 화면 공유하고 팀이 같이 봄 | T4 (저렴) |
| 본 학습 | EXAONE-7.8B QLoRA. 실행 시간대를 미리 정하고 1~2명만 실행 | A100 |

## 기본 흐름 (`playground/`의 노트북 또는 `ml/finetune/`)
1. GitHub 토큰은 노트북에 직접 쓰지 말고 **Colab Secrets(왼쪽 열쇠 아이콘)** 에 저장
2. `git clone` → `pip install` → Drive 마운트 → `python -m ml.finetune.train_lora ...`
3. **체크포인트/어댑터는 Drive에 저장** (세션이 끊기면 Colab 디스크는 사라집니다)
4. 학습 설정과 결과 요약을 `experiments/LOG.md`에 기록 (모델 파일은 Git에 올리지 않음)

## 주의
- 학습 데이터(`sft_train.jsonl`)는 로컬에서 만들어 Drive 공유 폴더에 올리고, Colab이 그것을 읽습니다.
- **AI-Hub 데이터를 Drive로 공유해도 되는지는 AI-Hub 이용정책을 확인하세요.** 각자 신청해서 받는 것이 가장 안전합니다.
